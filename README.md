# 大肥鱼 · 标签桌宠 v0.3.1

DeepSeek 社区二次元「大肥鱼」默认住在网页内容的右上角。桌宠和垃圾桶可一起拖动，下方直接放置当前标签的白名单开关，另有一个配置页。

## 怎么用

1. 解压 `dist/dafeiyu-v0.3.1.zip`。
2. 打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。也可直接加载仓库里的 `extension/`。
3. 打开普通网页，右上角就有大肥鱼和垃圾桶。更新插件后刷新已打开的网页。
4. **点击垃圾桶**，弹出小窗；**点击小窗内的标签**，立即从垃圾桶取回，并激活对应标签／浏览器窗口。
5. **直接点击垃圾桶下方的开关**，即可将当前页面加入或移出白名单，无需展开任何面板。旁边的小箭头展开保护说明，里面的配置按钮打开配置页。
6. **按住桌宠或垃圾桶拖动**，两者一起移动。位置在本机保存，刷新和新页面自动恢复；窗口缩小时保持在可见范围，小窗会根据剩余空间向上或向下展开。普通单击仍可整理或打开垃圾桶，拖动松手不会误触。

无需单独打开标签管理页。浏览器工具栏图标会打开同样的垃圾桶小窗，便于在不支持注入的页面或关闭桌宠后使用。

## 收纳行为

- 默认超过 **60 分钟**未交互后收纳，每分钟巡视一次。点击、键盘操作、滚动、切换到标签及导航会重置闲置时间；不记录按键或输入内容。
- 垃圾桶按**最后交互时间从新到旧**排列，最近用过的标签在前。网页小窗、工具栏弹窗和搜索结果采用相同顺序。
- 每个窗口当前使用的标签、固定标签、正在播放声音的标签、白名单标签默认受保护。
- 收纳时，大肥鱼走向页面顶部，拖着带有实际标签标题的小卡片回到垃圾桶。平时有眨眼与小动作；可关闭，并尊重系统「减少动态效果」。
- **收纳不等于关闭**：实际标签被放入折叠的 Chrome 分组，仍可恢复。默认不开启休眠。
- **清空前确认**：真正关闭确认时列出的标签。确认后新收纳的标签不会被误关；已重新使用或受保护的标签会保留。
- 可在配置中启用「收纳时休眠」，通过 `chrome.tabs.discard` 请求释放页面内存；Chrome 拒绝休眠时仍保留收纳状态。取回休眠标签时会重新加载，未保存的网页状态可能丢失。
- 单标签白名单随标签关闭、浏览器重启或扩展重载失效；配置页中的整站规则会保留，并覆盖子域名。
- 回收站记录放在 `chrome.storage.session`，避免跨浏览器会话误用标签 ID；后台休眠后恢复记录。新会话会从实际回收站分组恢复收纳状态，普通标签重新开始计时。

Chrome 普通扩展无法在**原生标签栏**上绘制或拖动角色，所以角色与搬运卡片动画位于网页内容中，后台同步管理真实标签。Chrome 内部页、扩展商店、其他扩展页面及隐身页面不注入桌宠；网页全屏时自动隐藏。

## 配置页

闲置时间、自动收纳、固定／声音保护、可选休眠、桌宠显示、动画，以及可选整站白名单。所有数据保存在本机，无后端、无账号、无分析追踪。角色素材已随包提供，运行时不访问素材网站。

## 开发

原生 JavaScript、Manifest V3，Chrome 120+。运行插件本身无需 npm 依赖，也没有常驻开发服务器。

```bash
cd /workspace/chrome_cleaner
npm ci --cache /workspace/.npm-cache --ignore-scripts --no-audit --no-fund
npm run check
npm test
npm run test:ui
npm run build
```

Node.js 22+；当前使用 Node.js 24.22.1。测试使用锁定版本的 Playwright Core 和系统 Chromium，可用 `CHROMIUM_PATH` 指定浏览器。直接使用当前独立云任务的检出目录，无需新建 Git worktree。

测试命令：

- `check`：Manifest、资源、JavaScript 语法、扩展页 CSP 检查。
- `test`：**28 项通过**，包括收纳规则、保护逻辑、后台生命周期、页面消息边界和点击取回激活流程；Chrome API 使用合约模拟。
- `test:ui`：**24 项通过**。在 Chromium 中实际渲染和操作网页桌宠、垃圾桶、外露白名单开关、工具栏弹窗、配置页，并验证整体拖动、位置保存、边界约束和拖动后不误触；Chrome API 模拟。测试使用离线页面，截图在 `artifacts/`。
- `test:e2e`：加载真实扩展、调用原生 Chrome API 的独立脚本。**当前云环境禁止加载开发者扩展，原生流程未验证**；此前启动尝试未能启动扩展后台，未更改管理员策略。需要在允许开发者扩展的 Chromium 环境执行 `CHROMIUM_PATH=/path/to/chromium npm run test:e2e`。
- `build`：生成 `dist/dafeiyu-v0.3.1.zip`，只包含插件运行文件和随包素材许可。

UI／后台模拟测试通过，不代表原生 Chrome API 验证通过。

## 结构

```text
extension/
  manifest.json          权限与 Manifest V3
  background.js          真实标签、闲置检查、收纳与取回
  core.js                设置校验与保护规则
  content.js / pet.css    可拖动桌宠、垃圾桶小窗、外露白名单开关
  popup.html / popup.css  工具栏中的同款小窗入口
  options.html/js/css     唯一独立页面：配置
  ui.js                  扩展消息客户端与配置页提示
  assets/                本地角色图集、图标与随包许可
```

权限用途：`tabs` 查询、激活、休眠和关闭标签；`tabGroups` 管理折叠回收站；`alarms` 每分钟检查；`storage` 本机设置与会话状态；`scripting` 在安装时为已打开网页注入桌宠；HTTP／HTTPS 网站权限用于交互计时和网页桌宠。

素材来源及许可保存在 `extension/assets/SOURCE.txt`、`DAFEIYU-LICENSE.txt` 和 `DAFEIYU-ASSET-LICENSE.md` 中，使用界面不展示署名。
